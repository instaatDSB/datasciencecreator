# THE AI CODING AGENT PLAYBOOK

*A beginner-friendly guide to working with AI coding agents — from your first instruction to a reliable development workflow.*

Publisher: @data.science.beginners

## What this is

A 32-page beginner-friendly ebook that teaches non-technical readers,
students, and junior developers how to work with modern AI coding agents
(Claude Code, Codex, Cursor, GitHub Copilot's agent mode, Gemini CLI, and
similar tools) using a repeatable eight-stage workflow, not a bag of prompts.

The central idea is: **prompt ≠ workflow**. Good results come from good
systems around the prompt, not from clever sentences inside it.

## The eight-stage operating system

```
DEFINE → CONTEXT → INVESTIGATE → BOUNDARIES → EXECUTE → VERIFY → REVIEW → LEARN
```

Each stage is a chapter. Page 28 codifies the whole system on one page; Page
29 walks through it end-to-end using the book's running example, the Student
Job Tracker.

## Running example

**Student Job Tracker** — a small web app that lets a student save
companies, record job applications, track application status, track
interview stages, record dates, and organize opportunities. It is the
vehicle for every workflow lesson in the book, never the subject.
