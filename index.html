S1 · StatisticsFormula sheet · 1 / 2

Descriptive formulas.

The formulas most often expected in analytics and data-science interviews.

Formula / rule

Arithmetic mean

μ = (1/N) Σ xᵢ

Population notation shown; sample mean is x̄ = Σxᵢ / n.

Formula / rule

Weighted mean

x̄_w = Σ(wᵢ · xᵢ) / Σ wᵢ

Use when observations contribute with different weights.

Formula / rule

Population variance

σ² = (1/N) Σ (xᵢ − μ)²

Sample variance commonly uses n−1 in the denominator (Bessel's correction).

Formula / rule

Standard deviation

σ = √σ²

Spread expressed in the original unit of the variable.

@data.science.beginners S1 · Statistics 07
S1 · StatisticsFormula sheet · 2 / 2

Descriptive formulas. continued

Standardization, spread of the middle 50%, and linear-association measures.

Formula / rule

Z-score

z = (x − μ) / σ

Number of standard deviations an observation is from the mean.

Formula / rule

IQR

IQR = Q₃ − Q₁

Common outlier fences: Q₁ − 1.5·IQR and Q₃ + 1.5·IQR.

Formula / rule

Covariance

Cov(X, Y) = E[(X − μₓ)(Y − μᵧ)]

Sign gives direction; magnitude depends on units.

Formula / rule

Pearson correlation

r = Cov(X, Y) / (σₓ · σᵧ)

Bounded in [−1, +1]; measures linear association only.

@data.science.beginners S1 · Statistics 08
S1 · ProbabilityFormula sheet · 1 / 3

Probability formulas.

Memorize the structure and, more importantly, know when each identity applies.

Formula / rule

Complement rule

P(Aᶜ) = 1 − P(A)

Useful when the complement is easier to compute.

Formula / rule

Addition rule

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

For mutually exclusive events, the intersection term is zero.

Formula / rule

Conditional probability

P(A | B) = P(A ∩ B) / P(B)

Requires P(B) > 0.

Formula / rule

Independence rule

P(A ∩ B) = P(A) · P(B)

This equality characterizes independent events.

@data.science.beginners S1 · Probability 09
S1 · ProbabilityFormula sheet · 2 / 3

Probability formulas. continued

Bayes updating, expectation, and the workhorse Binomial distribution.

Formula / rule

Bayes theorem

P(A | B) = P(B | A) · P(A) / P(B)

Posterior ∝ likelihood × prior.

Formula / rule

Expected value

E[X] = Σ x · P(X = x)

For continuous X, replace the sum with an integral over the PDF.

Formula / rule

Binomial PMF

P(X = k) = C(n, k) · pᵏ · (1 − p)ⁿ⁻ᵏ

n independent Bernoulli trials with constant success probability p.

Formula / rule

Standard error of the mean

SE(x̄) = s / √n

Uncertainty of the estimated mean decreases with √n.

@data.science.beginners S1 · Probability 10
S1 · ProbabilityFormula sheet · 3 / 3

Distributions & inference

The three distributions most often invoked, plus the workhorse test statistic.

Formula / rule

Normal PDF

f(x) = 1 / (σ√(2π)) · exp(−(x − μ)² / (2σ²))

Symmetric bell curve; 68 / 95 / 99.7 % within ±1 / ±2 / ±3 σ.

Formula / rule

Poisson PMF

P(X = k) = e⁻λ · λᵏ / k!

Counts of rare events in a fixed interval; mean = variance = λ.

Formula / rule

Exponential PDF

f(x) = λ · e⁻ᵏˣ, x ≥ 0

Waiting time between Poisson events; memoryless.

Formula / rule

Confidence interval

estimate ± critical value · SE

Critical value is z* or t* depending on assumptions and sample size.

Formula / rule

One-sample t-statistic

t = (x̄ − μ₀) / (s / √n)

Compare observed sample mean with a hypothesized mean. Under H₀ and normality, follows a t-distribution with n−1 degrees of freedom.

S2 · PythonPatterns · 1 / 3

Python patterns.

For Python, "formula" means reusable syntax and complexity patterns you should know cold.

Pattern

List comprehension

[f(x) for x in items if cond(x)]

Compact transform + filter. Prefer over `map + filter` for readability.

Pattern

Dict comprehension

{k: f(v) for k, v in pairs}

Useful for remapping and lookup creation.

Pattern

Generator expression

total = sum(x * x for x in nums)

Lazy; produces values on demand — no full list is built.

Pattern

Enumerate & zip

for i, (a, b) in enumerate(zip(xs, ys)): ...

Prefer enumerate over manual index counters; zip stops at the shortest iterable.

@data.science.beginners S2 · Python 18
S2 · PythonPatterns · 2 / 3

Python patterns. continued

Safe resource handling, flexible function signatures, and short generators/decorators.

Pattern

Safe file handling

with open(path) as f: text = f.read()

Context manager guarantees the file is closed even on exception.

Pattern

Exception handling

try: n = int(x) except ValueError: n = 0 finally: log.info("done")

Catch specific exceptions; avoid bare `except`.

Pattern

Flexible function

def f(a, *args, **kwargs): ...

Collect extra positional and keyword arguments.

Pattern

Simple generator

def read_lines(path): with open(path) as f: for line in f: yield line.rstrip()

Constant memory over huge files — the caller pulls one line at a time.

@data.science.beginners S2 · Python 19
S2 · PythonPatterns · 3 / 3

Python patterns. continued

Decorators, complexity rules, and a vectorized pandas contrast.

Pattern

Timing decorator

from functools import wraps def timed(fn): @wraps(fn) def w(*a, **kw): t = time.perf_counter() r = fn(*a, **kw) log.info(f"{fn.__name__} {time.perf_counter()-t:.3f}s") return r return w

@wraps preserves the wrapped function's name and docstring.

Complexity

Lookup costs

x in list → O(n) x in set → O(1) avg d[key] → O(1) avg sorted(xs) → O(n log n) (Timsort) nested loop → O(n²)

Reach for a set/dict whenever you need "does this exist?".

Pattern

Vectorize instead of loop

# slow: df["margin"] = [p - c for p, c in zip(df.price, df.cost)] # fast (vectorized in C): df["margin"] = df["price"] - df["cost"]

In pandas / NumPy, avoid Python-level iteration for row-wise arithmetic — the vectorized form is usually 10–100× faster.

S3 · SQLPatterns · 1 / 3

SQL patterns & templates.

These patterns solve a large percentage of practical SQL interview tasks.

Rule

Logical query order

FROM / JOIN → WHERE → GROUP BY → HAVING → SELECT (aliases created here) → DISTINCT → ORDER BY → LIMIT

Explains why SELECT aliases are not available in WHERE.

Pattern

Conditional aggregation

SUM(CASE WHEN status = 'paid' THEN 1 ELSE 0 END) AS paid_count

Count records meeting a condition inside a group.

Pattern

Safe denominator

SELECT numerator / NULLIF(denominator, 0) AS ratio

Avoid divide-by-zero errors; the result is NULL when denom is 0.

Pattern

Null fallback

COALESCE(preferred, fallback, 'unknown')

Return the first non-NULL expression.

Window functions carry a big share of interview questions.

Pattern

Top-N per group

WITH ranked AS ( SELECT *, ROW_NUMBER() OVER ( PARTITION BY category ORDER BY revenue DESC) AS rn FROM products) SELECT * FROM ranked WHERE rn <= 3;

Rank with ties

RANK() -- 1, 2, 2, 4 DENSE_RANK() -- 1, 2, 2, 3 ROW_NUMBER() -- 1, 2, 3, 4

Previous row

Compare a row with its previous period.

Running total

Cumulative metric by ordered rows.

@data.science.beginners S3 · SQL 28
S3 · SQLPatterns · 3 / 3

SQL patterns & templates. continued

Duplicates, existence, anti-joins, set operations, gaps-and-islands.

Pattern

Find duplicates

SELECT key, COUNT(*) FROM t GROUP BY key HAVING COUNT(*) > 1;

Classic duplicate detection pattern.

Pattern

Anti-join

SELECT u.* FROM users u LEFT JOIN orders o ON o.user_id = u.id WHERE o.user_id IS NULL;

Users who never ordered. Often clearer than NOT IN with NULLs.

Pattern

UNION vs UNION ALL

UNION -- removes duplicates UNION ALL -- keeps every row (cheaper)

UNION ALL is preferred when you know rows are unique.

Pattern

Gaps-and-islands

SELECT user_id, MIN(day) AS start, MAX(day) AS end FROM ( SELECT *, day - ROW_NUMBER() OVER ( PARTITION BY user_id ORDER BY day) * INTERVAL '1 day' AS grp FROM active_days) x GROUP BY user_id, grp;

Streaks of consecutive dates.

S3 · SQLWorked example

Worked example — top-3 per category.

A tiny schema, the query, and the shape of the result.

Schema

products

id | category | name | revenue ----+----------+------------+-------- 1 | shoes | runner v2 | 920 2 | shoes | trail x | 880 3 | shoes | flat 05 | 410 4 | shoes | canvas | 390 5 | bags | tote | 650 6 | bags | duffel | 420 7 | bags | sling | 380

7 products across 2 categories.

Query

Top 3 per category

WITH ranked AS ( SELECT id, category, name, revenue, ROW_NUMBER() OVER ( PARTITION BY category ORDER BY revenue DESC) AS rn FROM products) SELECT id, category, name, revenue FROM ranked WHERE rn <= 3 ORDER BY category, rn;

Swap ROW_NUMBER for DENSE_RANK if you want ties to share a rank.

Result

Expected output

id | category | name | revenue ---+----------+-----------+-------- 5 | bags | tote | 650 6 | bags | duffel | 420 7 | bags | sling | 380 1 | shoes | runner v2 | 920 2 | shoes | trail x | 880 3 | shoes | flat 05 | 410

Six rows — the top three per category, ordered by rank inside each partition.

Cleaning + preprocessing formulas.

These formulas recur in EDA, feature preparation, and interview questions.

Formula

Missing percentage

missing% = missing_count / total_rows × 100

Use per column and inspect patterns, not just totals.

Formula

IQR outlier fences

lower = Q₁ − 1.5 · IQR upper = Q₃ + 1.5 · IQR

A heuristic, not a universal definition of "bad data".

Formula

Z-score

z = (x − μ) / σ

Often flag |z| > 3 for roughly normal variables.

Formula

Standardization

x′ = (x − μ_train) / σ_train

Fit μ and σ on training data only.

Formula

Min-max scaling

x′ = (x − min_train) / (max_train − min_train)

Maps training range approximately to 0 – 1.

Formula

Robust scaling

x′ = (x − median_train) / IQR_train

More resistant to strong outliers.

Formula

Log transform

x′ = log(1 + x)

Common for right-skewed non-negative variables.

Formula

Frequency encoding

enc(c) = count(c) / N

Replace category by observed frequency; fit using training data.

Imbalance + a real pipeline.

Two class-imbalance formulas and the pipeline that keeps everything leakage-safe.

Formula

Class-weight heuristic

w_c = N / (K · N_c)

Inverse-frequency style class weighting. K = number of classes.

Formula

SMOTE interpolation

x_new = xᵢ + λ · (x_nn − xᵢ), 0 ≤ λ ≤ 1

Synthetic point along the line to a minority-class neighbor.

sklearn pattern

Leakage-safe pipeline

from sklearn.pipeline import Pipeline from sklearn.compose import ColumnTransformer from sklearn.impute import SimpleImputer from sklearn.preprocessing import StandardScaler, OneHotEncoder from sklearn.linear_model import LogisticRegression pre = ColumnTransformer([ ("num", Pipeline([("imp", SimpleImputer(strategy="median")), ("sc", StandardScaler())]), num_cols), ("cat", Pipeline([("imp", SimpleImputer(strategy="most_frequent")), ("oh", OneHotEncoder(handle_unknown="ignore"))]), cat_cols), ]) model = Pipeline([("pre", pre), ("clf", LogisticRegression(class_weight="balanced"))]) model.fit(X_train, y_train) # fits scalers, encoders, and model on TRAIN only model.predict(X_test) # same transforms applied at inference

The whole pipeline fits on training data — no scaler or encoder ever sees the test set.

S5 · MLRegression formulas · 1 / 2

Regression formulas.

Know what each metric penalizes and what a "good" direction means.

Formula

Linear regression

ŷ = β₀ + Σ βⱼ · xⱼ

Each βⱼ is the expected change in ŷ per unit change in xⱼ, holding others fixed.

Formula

Residual

eᵢ = yᵢ − ŷᵢ

Model error for one observation.

Formula

MAE

MAE = (1/n) Σ |yᵢ − ŷᵢ|

Robust relative to squared-error metrics.

Formula

MSE

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

Penalizes large errors more heavily.

@data.science.beginners S5 · ML 46
S5 · MLRegression formulas · 2 / 2

Regression formulas. continued

RMSE, R², and the two shrinkage penalties.

Formula

RMSE

RMSE = √MSE

Same unit as the target.

Formula

R²

R² = 1 − SS_res / SS_tot

Fraction of variance explained vs a mean baseline. Can be negative when a model does worse than the mean.

Formula

L1 regularization

Loss + λ · Σ |βⱼ|

Can drive some coefficients exactly to zero (feature selection).

Formula

L2 regularization

Loss + λ · Σ βⱼ²

Shrinks coefficients smoothly; rarely exactly zero.

Classification formulas.

Start from the confusion matrix; every metric is a different view of errors.

Formula

Sigmoid

p = 1 / (1 + e^(−z))

Maps real-valued logit z to probability 0 – 1.

Formula

Logit (log-odds)

log(p / (1 − p)) = β₀ + Σ βⱼ · xⱼ

Linear relationship in log-odds for logistic regression.

Formula

Accuracy

(TP + TN) / (TP + TN + FP + FN)

Can be misleading with class imbalance.

Formula

Precision

TP / (TP + FP)

Of predicted positives, how many were correct?

@data.science.beginners S5 · ML 48
S5 · MLClassification formulas · 2 / 2

Classification formulas. continued

Recall, specificity, F1, and calibrated log loss.

Formula

Recall / sensitivity

TP / (TP + FN)

Of actual positives, how many were found?

Formula

Specificity

TN / (TN + FP)

Of actual negatives, how many were correctly rejected?

Formula

F1 score

F1 = 2 · (Precision · Recall) / (Precision + Recall)

Harmonic mean balances precision and recall.

Formula

Binary log loss

−(1/n) Σ [ y · log p + (1 − y) · log(1 − p) ]

Rewards calibrated confidence and heavily penalizes confident wrong predictions.

Distance & impurity.

How several common algorithms decide what is "close" or "pure".

Formula

Euclidean distance

d(x, y) = √ Σ (xⱼ − yⱼ)²

Common KNN/K-means distance; scale matters.

Formula

Manhattan distance

d(x, y) = Σ |xⱼ − yⱼ|

Alternative distance less dominated by one large coordinate difference.

Formula

Gini impurity

Gini = 1 − Σ pₖ²

Zero for a pure node.

Formula

Entropy

H = − Σ pₖ · log₂ pₖ

Uncertainty/impurity measure used in tree splitting.

IG = H(parent) − weighted H(children)

Rapid fireSelf-test · 1 / 2

Rapid-fire self-test — I

Aim for one clear answer in 20 – 40 seconds. Suggested one-liners on the right.

  1. 01Mean vs median — which survives outliers better?
    2. Median. The mean is pulled by extreme values; the median depends only on order.
  2. 02What changes in Bayes theorem after observing evidence?
    3. The prior becomes the posterior: P(A|B) = P(B|A)·P(A) / P(B).
  3. 03List vs tuple vs set vs dict — when do you choose each?
    4. List ordered + mutable; tuple ordered + immutable (safe keys, records); set unique membership; dict key → value lookup.
  4. 04Why is set membership usually faster than list membership?
    5. Sets use a hash table — O(1) average lookup — while list membership is a linear scan (O(n)).
  5. 05WHERE vs HAVING?
    6. WHERE filters rows before aggregation; HAVING filters groups after aggregation.
  6. 06ROW_NUMBER vs RANK vs DENSE_RANK?
    7. All rank rows in a partition. Ties: ROW_NUMBER unique, RANK gaps (1,2,2,4), DENSE_RANK no gaps (1,2,2,3).
  7. 07Why can a LEFT JOIN create duplicate-looking rows?
    8. When the right table has multiple matches per key, each left row is repeated once per match.
  8. 08Why must scalers and imputers be fit on training data only?
    9. Fitting on test/val leaks future information into training, inflating scores.
@data.science.beginners Rapid fire 58
Rapid fireSelf-test · 2 / 2

Rapid-fire self-test — II

Target: one clear answer per question in 20 – 40 seconds, with no unnecessary jargon.

  1. 09Standardization vs min-max scaling?
    2. Standardize to μ=0, σ=1 (assumes roughly normal, no fixed range). Min-max to [0,1] (sensitive to outliers, keeps distribution shape).
  2. 10What is leakage?
    3. Any information from outside the training slice — future data, target-derived features, test-fit scalers — sneaking into training.
  3. 11Bias vs variance?
    4. Bias = error from oversimplifying; variance = error from being too sensitive to training data.
  4. 12MAE vs RMSE?
    5. Both measure error in target units. RMSE penalizes large errors more; MAE is more robust to outliers.
  5. 13Precision vs recall?
    6. Precision = of predicted positives, how many are right. Recall = of actual positives, how many did we catch.
  6. 14What does cross-validation estimate?
    7. The model's generalization performance on unseen data, more stably than a single held-out split.
  7. 15L1 vs L2 regularization?
    8. L1 (lasso) can zero coefficients — implicit feature selection. L2 (ridge) shrinks coefficients smoothly.
